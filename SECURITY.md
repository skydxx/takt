# Security policy

Проект находится в активной миграции и не предназначен для публичного
production-деплоя без отдельного security review.

Не отправляйте в issues токены Telegram, `.env`, базы, пользовательские
сессии, ключи шифрования или выгрузки кабинетов маркетплейсов. Для сообщения
о проблеме используйте приватный канал владельца проекта.

Перед деплоем:

1. Перевыпустите токен Telegram из локального `.env`.
2. Задайте отдельный `FLASK_SECRET_KEY` для production.
3. Проверьте, что в git не попали `data/`, базы, логи и архивы.
4. Не храните пароли кабинетов Ozon/WB в проекте или логах.
5. Перед отправкой deploy-архива запускайте `pack_for_deploy.sh`: он принимает
   только `.env.example` и исключает `.env`, базы, логи, `data/` и архивы.
