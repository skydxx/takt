# Liquid glass — файлы для лендинга

7 секунд · 1440 × 1440 · 24 кадра/с · без звука.

Четыре объёмные стеклянные формы собираются вокруг матового графитового центра, раскрываются и останавливаются. Начальная и конечная позы совпадают. Камера и освещение также возвращаются к исходному состоянию.

| Файл | Назначение |
| --- | --- |
| `liquid-glass-alpha.webm` | Видео VP9 с прозрачным фоном. |
| `liquid-glass.mp4` | Видео H.264 с однородным фоном #050505. |
| `liquid-glass-poster.webp` | Лёгкий прозрачный постер до загрузки видео и для режима уменьшенного движения. |
| `liquid-glass-scene.blend` | Редактируемая 3D-сцена Blender с материалами, светом, камерой и анимацией. |

Для страницы достаточно видео и постера. Исходник Blender загружать на сайт не требуется.

## Вставка

Положите видео и постер в одну папку. Пример для тёмного блока:

```html
<video
  class="liquid-glass"
  autoplay loop muted playsinline
  preload="metadata"
  poster="/media/liquid-glass-poster.webp"
  width="1440" height="1440"
  aria-hidden="true"
>
  <source src="/media/liquid-glass-alpha.webm" type="video/webm">
  <source src="/media/liquid-glass.mp4" type="video/mp4">
</video>

<style>
  .liquid-glass {
    display: block;
    width: min(100%, 500px);
    height: auto;
    aspect-ratio: 1;
    object-fit: contain;
    background: transparent;
  }
</style>
```

Проверьте поддержку прозрачного WebM в целевых браузерах. Для предсказуемого совпадения с тёмным фоном можно использовать MP4 и цвет секции `#050505`.

При `prefers-reduced-motion: reduce` показывайте постер, не запускайте видео автоматически. Для однократного показа фильма уберите `loop`: видео остановится в финальной позе.

## Исходник

Сцена создана и отрендерена в Blender 4.5 LTS / Cycles. Стекло — объёмная геометрия с преломлением, IOR 1.46; освещение — студийные источники и мягкие отражающие световые карты. Фон вне скульптуры имеет альфа-канал. Отражённая и преломлённая студия внутри стекла записаны в изображение: видео рассчитано на тёмный лендинг.

Анимация находится на кадрах 1–168. Начальная и финальная паузы намеренные. Все формы, камера, материалы и движение доступны для редактирования.
