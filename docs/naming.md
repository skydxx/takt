# Название продукта

Рабочее имя продукта: **Такт / Takt**. Оно передаёт основную идею: все точки сети, смены и деньги работают в одном ритме.

Кандидаты для проверки:

- Такт — короткое самостоятельное имя без привязки только к сменам;
- Открылось — хорошо отражает контроль открытия;
- Пунктир — коротко, но может быть слишком абстрактно;
- ПВЗ Контроль — понятно, но слабее как бренд;
- СменаТочка — функционально, но звучит хуже.

Финальное имя выбираем после проверки домена, товарного знака, Telegram username и поисковой выдачи. До проверки нельзя печатать бренд на сайте и в рекламных материалах.
